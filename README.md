# Lanczos Gaussian Sampler (LGS)

Code for the NeurIPS 2026 paper *The Value of Covariance Matching in Gaussian DDPMs and the Lanczos Sampler*.

LGS is a training-free, matrix-free method for sampling from the full posterior covariance of a pretrained Gaussian DDPM, using only Jacobian-vector products of the score network.
